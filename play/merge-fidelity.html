Create one self-contained HTML file with no dependencies that independently proves deterministic graded merge fidelity.

Requirements:
- Represent two independently formed histories as dimensions keyed by name and logical tick.
- Compute a SHA-256 content hash from canonical JSON for every declared value and independently verify all hashes before merging.
- Fail closed: if any input hash fails, produce no merged result.
- Join on dimension and tick. A shared dimension is mergeable only when every overlapping tick has the same content hash.
- Include three shared dimensions: two contradiction-free and one contradictory, plus one-sided dimensions on both histories.
- Compute and display the exact score as numerator / denominator and decimal: mergeable shared dimensions / all shared dimensions.
- Merge aligned shared dimensions and all one-sided dimensions. Preserve each conflicted dimension as two named parallel alternatives without choosing a winner.
- Show exact tick keys, full content hashes, conflict pairs, resulting dimensions, assertions, and a deterministic operation log.
- Add a mutation that silently overwrites the conflicted dimension with one side and make an independently computed preservation assertion turn red.
- Provide reset, keyboard-accessible controls, aria-live feedback, reduced-motion handling, and light/dark theme support.

Do not hard-code the score or merge result. Derive them from the current histories. Return the complete runnable HTML and explain one way to deliberately break the invariant.

# Frame Chains public evidence

This directory is a **synthetic, deterministic reproduction bundle** for the
mechanisms described in the Frame Chains paper. It contains no raw estate
records.

## Privacy boundary

The bundle intentionally excludes:

- network addresses, hostnames, MAC addresses, and device identifiers;
- usernames, email addresses, home-directory paths, and account metadata;
- credentials, keys, tokens, cookies, and authorization material;
- private repository names, source files, prompts, documents, and inventories;
- raw frames, logs, or artifacts from the author's physical estate.

All actors use synthetic labels such as `node-a`. All payloads were written for
this public fixture. The aggregate field observations already printed in the
paper remain classified as `aggregated-field-observation`; this bundle does not
claim to independently reproduce those private runs.

## Reproduce

```sh
npm run evidence:generate
npm run evidence:check
```

`evidence:generate` deterministically recreates `evidence/v1/`.
`evidence:check` then:

1. compares generated bytes with the committed release;
2. recomputes every manifest digest and frame/content hash;
3. derives each scenario result with an independent verifier;
4. proves deliberate mutations turn the corresponding invariant red;
5. scans the complete public bundle for network addresses, local hostnames,
   user paths, emails, credentials, token formats, and non-synthetic node IDs.

If the privacy scanner reports anything, the release must not be published.

## Evidence classes

- `publicly-reproducible-mechanism` means the committed synthetic fixture and
  verifier reproduce the algorithmic claim.
- `aggregated-field-observation` means the number is reported from the retained
  private engineering record. Only the already-public aggregate is present;
  the underlying estate record is intentionally withheld.

The manifest at `v1/manifest.json` binds every release data file and the
generator, independent verifier, and privacy gate by exact byte length and
SHA-256. The Git tag binds the surrounding documentation and package command.

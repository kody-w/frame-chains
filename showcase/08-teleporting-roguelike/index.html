Scope

What this proves

  • Canonical browser SHA-256 detects byte changes.
  • Parent links, not wall clocks, define total dependency order.
  • Independent devices reconstruct the same canonical world bytes.
  • An offline branch can be replayed onto a newer head when its declared reads remain ancestors.
Boundary

What this does not prove

This is a deterministic, synthetic, single-browser model. It does not model signatures, hostile key custody, network transport, consensus among competing writers, or production persistence. Device identities and clocks are synthetic. The chain is kept in memory and intentionally disappears on reset or refresh.

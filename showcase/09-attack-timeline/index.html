      Scope

      A proof of rejection boundaries, not a production trust system.

      • This page uses canonical JSON and the browser’s real Web Crypto SHA-256. It does not use substitute hashes.
      • Signatures, identities, distributed transport, persistence, consensus, and key custody are intentionally modeled—not claimed.
      • The synthetic high-water mark represents trusted durable state. A production system must protect that anchor independently.
      • Structural validity is not semantic truth. That is why semantics, causality, concurrency, and provenance are separate detectors.
      • A rejection preserves the last verified projection and retains the submitted bytes for audit. Nothing here silently “repairs” hostile input.
      No network, libraries, fonts, or assets.
